# Troubleshooting

> **For:** symptom → cause → fix, keyed by the message on screen. **Also see:** [setup.md](setup.md) · [running.md](running.md) · [verification/p1-agy-runtime.md](verification/p1-agy-runtime.md).

| Symptom | Cause | Fix |
|---|---|---|
| `run failed: run: the driver pin is not live-verified — checks 1, 2, 4, 5, 6 … are still pending` | The pin gate. The listed checks have not been run in a signed-in `agy` session | Run the checks and record them in `docs/verification/p1-agy-runtime.md`, flip them to `pass` in `plugin/agy/telemetry/fairnessPin.mjs` in the same commit — or pass `--allow-unverified-pin` and accept `pin.verified: false` in the manifest |
| `run: could not launch 'agy'` | Not on PATH in the shell that ran node | `export PATH="$HOME/.local/bin:$PATH"`, or `--agy-bin=$HOME/.local/bin/agy` |
| `driver-stderr.log`: `Waiting for authentication (timeout 60s)…` then `authentication failed or timed out` | agy is not signed in; print mode cannot complete the browser flow | Run `agy` interactively once and finish Google Sign-In. `agy models` must list models before a run |
| `driver-stderr.log` names an allow-rule and a soft-denied tool | `--dangerously-skip-permissions` missing (check 6) | `run.mjs` passes it; if you built the argv by hand, add it |
| `preflight.json` has `ok: false` and the run halts | The bridge cannot build an adapter: a missing credential, a policy naming an adapter with no door | Read `halt_reason`. `npm run verify` names the missing variable and where to set it |
| Every packet routes to Opus, cost several times the estimate | Preflight was skipped and the mechanical tier was unreachable | The conductor prompt's rule 0 forbids this; check `gates.jsonl` and `preflight.json` exist |
| `MCP error -32000: Connection closed` from `dispatch.mjs` | A sandbox that allows children but denies piped stdio (check 2) | Start agy without `--sandbox`; the diagnosis in the error names the headless way out |
| `MCP error -32001: Request timed out` | A client timeout below the adapter's worker timeout | `driverClient.ts` waits 1,800 s; the test suite checks it exceeds every policy's `worker_timeout_sec` and the Claude Agent SDK adapter's 1,740 s default |
| A Claude dispatch fails with `claude-agent-sdk timeout after …s` | The Opus call ran past the adapter's timeout (default 1,740 s, or the model's `worker_timeout_sec`) | The attempt is booked from the usage the stream reported before the stop (`usage_from_frames: true`), never as $0. Split the packet, or raise `worker_timeout_sec` on the model below the client's 1,800 s |
| The bridge starts with empty credentials under the MCP route | agy did not expand `${VAR}` in `mcp_config.json` (check 5) | `--inline-env` |
| A write the pipeline instructs is refused | The write contract (`.sdlc/local/write-contract.json`) | Read `.sdlc/local/guard-decisions.jsonl`; re-open Gate 0 to widen the allowlist, or set `strict: false` |
| `manifest.md` appears instead of `manifest.json` | The model wrote its own manifest | `manifest.json` is code-written by `plugin/agy/manifest.mjs`; the model's file is advisory |
| The modeled driver line looks several times too high, or `run …: N driver result(s) reported counters that no token reading adds up to` | agy's counters did not prove how `input_tokens` and `output_tokens` nest, so the dearest reading was booked | Read `driver_usage.token_readings` in `driver-manifest.json`. Record which layout agy uses (check 17 in [the P1 doc](verification/p1-agy-runtime.md); `tools/p1/live-checks.sh 16` answers it) from one non-zero result |
| `run …: agy reported driver model(s) …, not the pinned …` | A model name in the stream that is not the policy's driver pin | The run is not comparable: re-run, and check `agy models` lists the pinned slug |
| `run: the driver model '…' has no price on …` | The dated price list has no period for the driver model on that day | Add the verified period to `plugin/mcp/model-dispatch/src/prices.ts`, or set `pricing_override: true` on the policy's `driver:` block to bill its card as custom |
| The report shows a driver **Range** instead of one figure | The run resumed agy at least once, and check 16 (usage across a resume) is pending | Run `tools/p1/live-checks.sh 16` and record it; until then the headline is the upper bound and `driver_usage.cost_usd_low` the lower |
| `run …: agy invocation(s) N reported no usage` | agy timed out (`--print-timeout`), crashed before its final `result` line, or failed with an all-zero error result (for example a lapsed sign-in) | The driver figure may be missing that invocation's tokens. Read `driver-stderr.log` and `driver_usage.invocations[N].last_status`; raise `--print-timeout` or sign in again |
| `run: the conversation being resumed ran on '…', and this launch pins '…'` | `--resume` with a different policy or driver pin than the launch that started the conversation | Resume with the `--policy` it names, or start a new run |
| `agsdk.usage_semantics_unverified` in the `MMO:` log | The agent-door worker ran an Antigravity SDK version whose usage totals have not been checked against Google's own token counter. It is billed on the larger reading, so its cost can be over- but not under-reported | Reinstall the pinned SDK (`npm run verify -- --fix`). To adopt the new version: run one delegation, compare its sidecar with Cloud Monitoring's `aiplatform.googleapis.com/publisher/online_serving/token_count` for that minute, and add the version to `AGY_USAGE_SEMANTICS` in `plugin/mcp/model-dispatch/src/delegation/workerProcess.ts` |
| `run: warning — the model-dispatch bridge is older than its source`, the same from `dispatch.mjs`, or `mcp-build-stale` from `npm run verify` | A pull changed `plugin/mcp/model-dispatch/src/` and nothing rebuilt `dist/`, which is what every runner imports. The fixes you pulled are not running | `npm run build`. `driver-manifest.json` → `bridge_build.stale` records whether a run used a stale build |
| `npm test` reports the MCP suite NOT RUN | `plugin/mcp/model-dispatch/node_modules` absent | `npm run verify -- --fix` (or `npm run build`), then `npm test` |
